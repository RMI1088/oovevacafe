# Ooveva Cafe Connect

Build a premium, professional, mobile-first business website for Ooveva – The In House Cafe in Hanamkonda, Telangana.



BUSINESS:

Name: Ooveva – The In House Cafe

Location: Back of Woodland, beside D-Mart, Subedari, Hanamkonda, Telangana 506001

Google Maps: https://maps.app.goo.gl/b1rK7KLvhA7gyPFp9?g_st=ac



IMPORTANT DATA RULE:

Use the Google Maps listing as the primary source for publicly available business information.



The Google Maps listing contains a menu. Use the available menu information from the listing and accurately reproduce:



- Menu categories

- Item names

- Descriptions

- Prices

- Available menu images



Do NOT invent menu items, prices, phone numbers, opening hours, reviews, awards, social-media accounts, or other business information.



If information cannot be accessed automatically, create an editable placeholder rather than guessing.



OVERALL GOAL:

The finished website should look like a professionally designed website made specifically for Ooveva, NOT like a generic AI-generated template.



It should feel premium, modern, warm, inviting, trustworthy and appropriate for a café.



DESIGN:



- Premium café aesthetic

- Warm and welcoming visual direction

- Elegant typography

- Excellent food photography

- Attractive use of whitespace

- Sophisticated cards and sections

- Subtle animations

- Smooth scrolling

- Modern buttons

- Beautiful hover effects on desktop

- Excellent mobile layout

- Responsive tablet and desktop layouts

- Fast loading

- Accessible contrast

- Clean visual hierarchy

- Avoid excessive animations or clutter



NAVIGATION:

Create a sticky responsive navigation bar containing:



Ooveva logo/name

Home

About

Menu

Gallery

Visit Us

Contact



On mobile, use a clean hamburger menu.



HERO SECTION:



Create a visually impressive hero section.



Display:

“Ooveva – The In House Cafe”



Add a short, elegant café introduction based only on information that can be verified.



Add two prominent buttons:



“View Menu”

“Get Directions”



Use attractive café/food imagery.



Include the location:

Subedari, Hanamkonda, Telangana



ABOUT SECTION:



Create an elegant About Ooveva section.



Use information available from the Google Maps listing where appropriate.



Do not make unsupported claims.



Write warm, natural copy that makes the café feel welcoming without exaggerating.



MENU SECTION:



This is one of the most important sections.



Use the menu available on the Ooveva Google Maps listing.



Recreate the menu accurately.



Organize items into their actual categories.



For every available item show:



- Item name

- Description, if available

- Price

- Image, if available



Create attractive menu cards.



Add category filters/tabs so visitors can easily browse the menu.



Make the menu highly readable on mobile.



Do not change prices.



Do not create fake items.



Do not add dishes simply because they are common café dishes.



If Google Maps provides menu images rather than structured information, create the website structure so those menu images can be displayed clearly.



Add a “View Full Menu” option if appropriate.



GALLERY:



Create a premium photo gallery.



Use available Ooveva photographs if they can legally and reliably be accessed.



Otherwise create clearly marked image placeholders that can easily be replaced.



Gallery should support:



- Café interior

- Food

- Drinks

- Atmosphere



Add a tasteful image lightbox.



VISIT US SECTION:



Create a large location section.



Display:



Ooveva – The In House Cafe

Back of Woodland, beside D-Mart

Subedari, Hanamkonda

Telangana 506001



Add a prominent:



“Get Directions”



button.



The button must open the supplied Google Maps location:



https://maps.app.goo.gl/b1rK7KLvhA7gyPFp9?g_st=ac



If possible, include an embedded map.



CONTACT SECTION:



Create a professional contact section.



Include only verified information from the Google Maps listing.



Possible elements:



- Phone

- WhatsApp

- Address

- Opening hours

- Google Maps

- Social media



Do NOT invent missing information.



If a phone number is available, make it clickable on mobile.



If a WhatsApp number is available, create a WhatsApp CTA.



If opening hours are available, display them clearly.



If any information is unavailable, make it editable.



CALL-TO-ACTION:



Add a beautiful final CTA section before the footer.



Use a short café-focused message such as:



“Good food. Good moments. See you at Ooveva.”



Keep this editable.



Buttons:

“View Menu”

“Get Directions”



FOOTER:



Include:



- Ooveva – The In House Cafe

- Address

- Navigation links

- Menu

- Contact

- Google Maps

- Verified social links, if available

- Copyright



FUNCTIONALITY:



Everything must work.



Check:



- Navigation

- Menu filters

- Menu buttons

- Google Maps button

- Phone button

- WhatsApp button

- Gallery/lightbox

- Mobile navigation

- Smooth scrolling

- External links

- Responsive layout



SEO:



Create proper:



- Page title

- Meta description

- Heading hierarchy

- Image alt text

- Local-business-friendly SEO structure



Use natural keywords such as:

“Ooveva The In House Cafe”

“cafe in Hanamkonda”

“cafe in Subedari”

only where appropriate and without keyword stuffing.



PERFORMANCE:



Optimize for mobile users.



- Compress/optimize images

- Lazy-load gallery images

- Avoid unnecessary animations

- Keep page loading fast

- Avoid unnecessary libraries

- Make buttons easy to tap on phones



EDITABILITY:



Make it easy for me to update:



- Menu

- Prices

- Food images

- Café images

- Phone number

- WhatsApp number

- Opening hours

- Social media

- About text



FINAL QUALITY CHECK:



Before considering the website finished:



1. Check every button.

2. Check every link.

3. Check the Google Maps directions link.

4. Check the menu against the Google Maps listing.

5. Make sure no information has been invented.

6. Check spelling.

7. Test mobile responsiveness.

8. Test desktop responsiveness.

9. Check image loading.

10. Remove unnecessary placeholder content.

11. Make the design feel like a real premium café website.

12. Make sure the website looks excellent on a typical Android phone.



The final result should look like a website that a professional web designer could confidently present to the café owner.
